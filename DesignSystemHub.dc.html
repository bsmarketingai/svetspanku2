Světspánku.cz · design systém

Přehled komponent a pravidel

Jedno místo pro kodéry: každá komponenta prototypu, všechny její varianty a stavy vykreslené živě ze zdrojových souborů (dc-import), popis chování a pravidla. Tokeny drží DesignSystem.dc.html, ladění komponent Komponenty.dc.html. Web je jen světlý. Štítek k rozhodnutí označuje varianty, mezi kterými se ještě vybírá – po výběru se nepoužité z přehledu skryjí.

Základy

Tokeny jsou převzaté z DesignSystem.dc.html (zdroj pravdy). Tady jen to, co kodér potřebuje mít po ruce; plná tabulka škál a kontrastů zůstává tam.

Pravidla

  • V komponentách se používají jen sémantické tokeny, nikdy číslo ze škály. Zápis var(--ss-token, #světláHodnota).
  • Každý textový token je ověřený na WCAG AA 4,5 : 1. Přemapováno kvůli kontrastu: neutral-500 nenese text (→ text.muted #5B6874), green-500 nenese text (→ #157A41), apricot-500 nenese text na bílé (→ apricot-700 #A4600C).
  • Konverzní barva je meruňková (action.buy). Zelená = success, červená = error. Nedostupné zboží je šedé.
  • Web je jen světlý (29. 10. 2026). Tmavé hodnoty v CSS zůstávají jako nepoužívaný kód – nová práce je neřeší.

Pravidla

  • Hover se nezjišťuje šířkou okna, ale dotazem (hover:hover) and (pointer:fine) – na dotykovém zařízení hover neexistuje.
  • Focus ring 0 0 0 3px rgba(41,96,147,.35) je vidět vždy, i při ovládání myší (:focus-visible, outline none).
  • Disabled = aria-disabled="true" + opacity .45; tlačítko zůstává v DOM a fokusovatelné, klik se jen zahodí.
  • Hover tlačítek a odkazů je jen změna barvy – bez nadzvednutí, stínu ani posunu šipky (sjednoceno 5. 11. 2026). Tabulka v DesignSystem § 7 ještě uvádí starší zdvih −1 px – platí tato.

Pravidla

  • Vlastní scrim / dialog / trap / Escape se do stránek ani komponent nepíše. Scrim vždy třída .ss-scrim (blur 16 px, diagonální závoj, teplé světlo) – výjimka jen lightbox galerie.
  • Nový obsah = nový řádek v registru Overlay (sc-if + statický dc-import). Obsah dostává data + onEvent(typ, a, b); onEvent("close") zavře okno.
  • Overlay props: open, variant, size, obsah, title, icon, iconTone, badge, closeLabel, primaryLabel/Variant/Href/Icon, secondaryLabel/Icon/Href, footerRow, footerMobileOnly, footerNote, flush, initialFocus, onBack/backLabel, getAnchor (popover), panelId.
  • Zaoblení 12, stín overlay 0 16px 40px .18, z-index drawer 410 / modál 500. Animace 200 ms drawer, 160 ms modál (prefers-reduced-motion vypne).
